# A C# consumer of the bdd-suite packages

A small workspace that uses the C# runtime the way another repository would:
through the `Smartpcr.BddSuite` and `Smartpcr.BddSuite.Testing` packages alone, under central
package management, with no path into this repository (docs/packages, E2).

| Part | What it is |
| --- | --- |
| `schema/actions.catalog.yaml` | Its catalog: the core imported by name (`bdd-suite:core`) and two actions, `greet.say` and `greet.shout`. `suite.schema.json` and `suite.schema.md` beside it are generated by the spec's `Build-Schema.ps1`. |
| `suites/` | `greeting.yml` (offline) and `loud.yml`, which uses `greet.shout`, an action `bddsuite.tests.yaml` does not list as offline, so its tests skip unless `BDD_SUITE_ALLOW_GUARDED=1`. |
| `Greeter.Suite` | Its extension (`GreeterExtension : IExtension`), on the `Smartpcr.BddSuite` package. |
| `Greeter.Suite.Cli` | Its own `suiterun`: `Runner.Run(args, ..., new GreeterExtension())`. |
| `Greeter.Suite.{MsTest,NUnit,XUnit}` | Its suites as tests: `Smartpcr.BddSuite.Testing` plus one framework; the build generates the tests from `bddsuite.tests.yaml`. |
| `Directory.Packages.props` | The versions, centrally; `BddSuiteVersion` is the release under test. |
| `nuget.config` | The local feed `artifacts/feeds/nuget` at the repository root for `Bdd.Suite*`, nuget.org for everything else (package source mapping). |

Run it (packs the runtime into the local feed first):

```powershell
pwsh -File samples/consumers/csharp/run-e2.ps1
# a machine that reaches nuget.org only through a mirror:
pwsh -File samples/consumers/csharp/run-e2.ps1 -Upstream https://<mirror>/nuget/v3/index.json
```

It restores into a package cache of its own (`artifacts/nuget-packages`), so the
packages just packed are the ones used, then checks the program's `lint`,
`list --name` and `run --name --progress`, and under each framework: every case
passes but the guarded one, which is not run; all pass with
`BDD_SUITE_ALLOW_GUARDED=1`; the `smoke` tag selects one case.
