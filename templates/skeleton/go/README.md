## The Go binding

`bindings/go`: `actions/actions.go` (one registration per action and its
handler), `actions/extension.go` (`actions.Extension`), `cmd/suiterun` and
`tests/` (the suites as `go test` tests, generated by `go generate`). The module,
`github.com/smartpcr/bdd-code-extension/runtimes/go` v{{version}}, is required
in `bindings/go/go.mod`. Needs Go 1.24 or later.

```powershell
cd bindings/go
go mod tidy                                    # once, writes go.sum
go build -o bin/suiterun.exe ./cmd/suiterun    # what Suite: Build lint tool runs
go generate ./tests                            # after adding or renaming a case or a suite
go test ./tests -v                             # every case; guarded suites skip
go test ./tests -v -run 'TestSuite_{{Namespace}}/echoes-text'   # one case
cd ../..

$suiterun = 'bindings/go/bin/suiterun.exe'
& $suiterun lint --path 'suites/*.yml' --schema-root schema --binding-check --binding go --strict
& $suiterun run  --path 'suites/*.yml' --schema-root schema --progress --results out/results.xml --trace-file out/trace.json
```

Reports: `out/results.xml` (NUnit 3; `--format junit` for JUnit) and
`out/trace.json` (one entry per step); `go test -json` for go's own. Under
`go test`, `BDD_SUITE_ALLOW_GUARDED=1` runs guarded suites and
`BDD_SUITE_TRACE_FILE=<path>` writes the trace.
