## Deviations from the plan

* **E9's workspace is the C# consumer in the default layout.** The
  extension activates on `test/e2e/schema/actions.catalog.yaml`, and the
  consumer samples keep theirs in `schema/` (each `suiterun` takes
  `--schema-root schema`). The scratch workspace copies the sample's catalog,
  schema and suites into `test/e2e/schema` and `test/e2e/suites`, with its
  `Directory.Packages.props`, so "default settings" holds.
* **The bundled linter makes no binding check.** DEC-P08 says binding checks
  still need the consumer's binding program; with the default target
  (`powershell`) a C#-only workspace would otherwise see `E201` on every one
  of its own actions. The status bar says so.
